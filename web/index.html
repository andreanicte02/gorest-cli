Go → WebAssembly

gorest-cli

A small Go client for the GoRest users API. This page runs the same Go package the CLI uses, compiled to WebAssembly — no backend involved.

View source Download the CLI

$ gorest list
Output will appear here.

How it works

  1. gorest/ is a plain Go package: typed models, context-aware requests and structured API errors, covered by tests against httptest.
  2. cmd/gorest wraps it as a CLI, released for Linux, macOS and Windows with GoReleaser.
  3. cmd/wasm exposes the same package to JavaScript through syscall/js; Go's net/http maps onto the browser's fetch.
  4. GitHub Actions builds the .wasm and deploys this page to GitHub Pages on every push.
